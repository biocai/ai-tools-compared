# 时间管理小助手 - 产品说明

> 来源: 百度网盘 苹果快捷指令资料
> 类型: 快捷指令 + 飞书多维表格 + 苹果日历联动

## 核心功能

1. **双击手机背部启动** - 通过"轻点背面"触控手势触发
2. **任务时间记录** - 开始时间、结束时间、持续时间、完成事项
3. **番茄钟模式** - 可选启用
4. **自动同步日历** - 任务完成后写入苹果日历app
5. **数据上传云文档** - 通过Webhook自动上传至飞书多维表格
6. **可视化仪表盘** - 飞书中自动生成时间数据看板

## 技术架构

```
iOS快捷指令 (触发端)
    ↓ 用户输入任务分类 + 内容
    ↓ 计时/番茄钟
    ↓ 完成后:
    ├→ 写入苹果日历 (本地CalDAV)
    └→ POST Webhook → 飞书机器人助手 → 新增多维表格记录
                                                    ↓
                                              飞书《时间数据》表
                                                    ↓
                                              飞书《我的时间仪表盘》
```

## 设备与限制

- 适用: iPhone / iPad / Mac
- iOS限制: 后台任务最长3分钟，计时过程中不能息屏
- 规避: 设置屏幕常亮，弹出选项时必须点击选项

## 飞书配置三步

### 第一步：复制仪表盘模板
- 飞书客户端 → 打开分享的模板 → 创建副本(私有) → 删除原模板

### 第二步：创建飞书机器人助手
- 搜索"飞书机器人助手" → 新建应用 → Webhook触发器
- Webhook参数:
```json
{
    "message_type": "text",
    "持续时长": 4,
    "完成内容": "文本",
    "时间类型": "文本",
    "时间类型-一级": "文本",
    "时间类型-二级": "文本"
}
```
- 操作: 新增多维表格记录 → 选数据表 → 映射字段

### 第三步：设置快捷指令Webhook地址
- 编辑快捷指令 → 粘贴Webhook地址 → 清空原地址

## 个性化配置

### 事项分类
- 在快捷指令编辑页找到"第二步：菜单设置"
- 一级分类和二级分类均可自定义
- 需保持三个部分且顺序一致

### 完成计时询问间隔
- 默认3秒后弹出"是否完成"
- 选择"继续计时"则3秒后再次弹出（无限循环）
- 长按调整间隔时间

## 日历集成

### 按事项类别显示不同颜色
1. 在苹果日历中添加与分类名称完全一致的日历（含emoji）
2. 每个日历设置不同颜色
3. 在快捷指令中将日历变量D指向对应日历
